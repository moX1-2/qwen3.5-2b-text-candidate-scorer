# 项目起点文件

公开包的 `origin/` 目录保留了项目最初的两份文件：

- [`1.docx`](../origin/1.docx)：2026-09-24 的三段早期讨论记录，并内嵌架构图。
- [`arch_image.png`](../origin/arch_image.png)：同一张架构图的独立图片文件。

这张图记录了最初的 0.8B 模型、特殊 token 和公共前缀缓存等设想。后续实际训练采用 Qwen3.5-2B 文本骨干，候选分支分别前向计算，没有实现图中的公共前缀缓存。实际实现与指标应以 `jev/train_cluster.py` 和 `docs/全流程复现.md` 为准。
